# Contributors

MinusPod is better because people run it, break it, fix it, and send their work back. This file credits external contributions that shipped in releases. If something of yours made it in without a mention, open an issue and it will be added.

## Code and features

- **Bryan Leboff ([@leboff](https://github.com/leboff))** - First implementations of the skip-FLAC-compression toggle, the `ENV_BACKED_SETTINGS` registry, and parallel ad-detection windows in the leboff/MinusPod fork (May 2026). Equivalent features shipped upstream in 2.5.23-2.5.25 (released in 2.5.27) without attribution; this credit corrects that.
- **[@kristofferR](https://github.com/kristofferR)** - Pass-2 category actions, DAI review safeguards, and related hardening, ported from the kristofferR/MinusPod fork in 2.90.0-2.90.1 (#679, #680, #681).

## Bug reports

- **[@s1shed](https://github.com/s1shed)** - Flagged the `audioBitrate` duplicate-key bug in `openapi.yaml` (PR #287), fixed in 2.5.27.
