UI reference

The single template to follow when adding or updating screens. Everything here is extracted from the live frontend code: index.css, themes.ts, buttonStyles.ts, and the shared components. Switch theme and mode above — every element must hold up in all of them, so build only with tokens.

Buttons

Five recipes, all in buttonStyles.ts — import them, never restyle. Outline renders as Secondary on purpose (the old bordered recipe vanished in dark mode). Sizing stays at the call site.

btnPrimary    = bg-primary text-primary-foreground hover:bg-primary/90
btnSecondary  = bg-secondary text-secondary-foreground hover:bg-secondary/80
btnOutline    = btnSecondary  (alias, kept for intent)
btnGhost      = text-muted-foreground hover:text-foreground hover:bg-accent
btnDestructive = bg-destructive text-destructive-foreground hover:bg-destructive/90
call site adds: px-3 py-1.5 text-sm rounded disabled:opacity-50 transition-colors
Mobile: collapse to icon-only 32×32 (h-8 w-8) with aria-label; show the text label from sm: up (hidden sm:inline). Keep the surrounding row’s tap target ≥44px with padding/gap.

Inputs & forms

Text/number fields sit on background with an input border and 8px radius. Selects are the one exception: secondary fill, 4px radius. Focus is always ring-2 ring-ring, never a recolored border. Numeric fields go through NumberInput, checkboxes through Checkbox.

Badges & status

One shape everywhere: px-2 py-0.5 text-xs rounded with a 20% tint fill. Status colors come from episodeStatus.ts — the only place raw palette hues (blue, yellow, purple, teal) are allowed.

Navigation, tabs & toggles

Top nav: ghost links, active = solid primary pill. Page-level views split with underline tabs. Compact binary choices (grid/list, sort) use a joined segmented toggle where active is also solid primary. Below sm the nav collapses behind the hamburger into a stacked list.

Overlays: modals, menus, toasts

All dialogs go through the shared Modal / ConfirmModal: backdrop bg-black/50 z-50 p-4, panel = card + shadow-xl, actions right-aligned in a bordered footer, Cancel (outline) before the confirm. Toasts stack fixed bottom-4 right-4.

Do / Don’t

The consistency rules that keep new features looking native.

Do
  • Import button recipes from buttonStyles.ts; add only sizing at the call site.
  • Use token colors so every theme works; check dark + Obsidian before shipping.
  • Build mobile-first: table → cards below sm, labels → icons with aria-label.
  • Reuse shared components: Modal, DropdownMenu, Checkbox, NumberInput, Pagination, CollapsibleSection, LoadingSpinner.
  • Give every interactive element transition-colors, disabled:opacity-50, and focus:ring-2 ring-ring.
  • Put error detail in title= on a short badge/label.
  • Add new statuses to episodeStatus.ts / segmentCategory.ts maps, not inline.
Don’t
  • Hardcode gray-* / white / hex colors — they break 19 of 20 themes.
  • Invent a bordered “outline” button; btnOutline is Secondary by design.
  • Add shadows to resting cards — shadow-lg/xl marks overlays only.
  • Mix badge shapes: it’s always px-2 py-0.5 text-xs rounded + 20% tint.
  • Use more than one Primary action per card/row; pair it with Secondary or Ghost.
  • Ship a desktop table without its mobile card variant.
  • Use rounded-full pills, gradients, or new fonts — Roboto only.
